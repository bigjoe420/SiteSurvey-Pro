================================================================================
Critical lessons for next session
================================================================================
1. RMT struct field order matters: rmt_symbol_word_t = {duration0, level0,
   duration1, level1}. Designated initializers must match declaration order.
2. BIT0/BIT1 are macros in esp_bit_defs.h. Never use them as variable names.
3. ESP_RETURN_ON_ERROR requires #include "esp_check.h".
4. Build via: powershell -File tools/idfenv.ps1 idf.py build
5. Flash via: powershell -File tools/idfenv.ps1 idf.py flash -p COM7
