Key truths to carry forward (KIMI.md §5.14):
Corollary 11: Non-blocking DMA flush is mandatory for responsive touch on 20 MHz SPI
Corollary 12: Forward nav = PRESSED, Back nav = CLICKED
Corollary 13: Lazy widget creation when init-time object count blocks UI task
Corollary 14: Adaptive lv_timer_handler() sleep caused black screen — fixed 10 ms only
Corollary 15: Animations on high-frequency refresh widgets are toxic on shared SPI buses — prefer LV_ANIM_OFF with change guards
Corollary 16: A lv_timer that only gates on a boolean flag is NOT free when hidden — must use lv_timer_pause()/lv_timer_resume() to literally remove it from LVGL's active timer list
Corollary 17: Canvas-based animations are the most expensive widget type on ESP32-C5 — benchmark lv_timer_handler() duration on-device; if it exceeds 5 ms, reduce update rate or simplify geometry
